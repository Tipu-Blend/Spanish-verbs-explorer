# Spanish Verbs Explorer

1,000 essential Spanish verbs with 18 tenses x 6 persons, plus a sentence checker.
Open `index.html` in a browser (double-click it).

## Status: early (v0.1)
- The sentence checker is **rule-based**. It catches common errors (ser/estar, tildes, verb agreement, subjunctive triggers, questions, etc.) but cannot judge all Spanish grammar.
- **Online grammar check and English translation** (LanguageTool, MyMemory) need internet and only work when the file is opened directly in a normal browser, not in some preview windows.
- The offline word-by-word gloss is rough, not a real translation.

## Known gaps
- Adjective gender agreement ("el día es hermosa")
- Joint subjects ("ella y yo es")
- Word-order and meaning errors
